AquaSense – Water Potability Prediction Using KNN

Project Overview

AquaSense is a Machine Learning project that predicts water potability using the K-Nearest Neighbors (KNN) classification algorithm.

Objective

To classify water samples as potable or non-potable based on their physical and chemical properties.

Dataset

Water Potability Dataset from Kaggle.

https://www.kaggle.com/datasets/adityakadiwal/water-potability

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Algorithm

K-Nearest Neighbors (KNN)

Methodology

1. Dataset collection
2. Data preprocessing
3. Missing value imputation
4. Feature scaling
5. Training and testing
6. K-value selection using GridSearchCV
7. Model evaluation

Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Conclusion

The project demonstrates how KNN can be used to classify water samples based on their recorded quality parameters.
